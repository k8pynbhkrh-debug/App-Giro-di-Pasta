# Giro: Pasta Night 🍝

Ein experimentelles Koch-Partyspiel als **Progressive Web App (PWA)**.

Die App unterstützt das Partyspiel **Giro: Pasta Night**, bei dem Spieler versteckte Rezepte kochen und andere versuchen, diese zu erraten.

---

## 🎮 Spielidee

Spieler ziehen eine **Nudelsorte** und ein **Rezept** und kochen das Gericht.
Die anderen Spieler versuchen währenddessen zu erraten, welches Rezept gekocht wird.

Punkte gibt es für:

* richtige Tipps
* falsche Tipps (Minus)
* besonders gut verschleierte Rezepte

Das Spiel endet, wenn alle satt sind.

Mehr Details im offiziellen Regelblatt.
